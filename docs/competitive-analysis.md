| 字段 | 内容 |
|------|------|
| 产品 | 证目 |
| 日期 | 2026-11-21（修订：补法宝AI加 + 可借鉴/可超越） |
| 目的 | 支撑「证明目的 + 可核验 + 对照修订」差异化；作业可交 |

**证目一句话（对照锚点）：** 诉讼律师证据目录「证明目的」高质量生成 + 法条/引用可核验 + 对照修订（律师终审）；不做一键可上庭文书；时间线辅助非主打。

**标注约定：** `[公开]` = 官网/官方介绍/公开采购通知可核；`[推断]` = 基于公开能力对证目场景的产品判断，非用户原话；`[访谈]` = 仅调研纪要/问卷已记录内容。

## 1. 分析框架

| 维度 | 含义 |
|------|------|
| 定位 | 卖给谁、解决什么主任务 |
| 核心能力 | 生成 / 检索 / 合同 / 办公执行等 |
| 价格 / 获取 | 免费、席位订阅、机构采购、账号形态 |
| 准确与幻觉 | 访谈评价 + 产品是否强调溯源 |
| 是否覆盖「证明目的」 | 是否针对证据目录证明目的工作流 |
| UI / 账号摩擦 | 体验与席位/登录摩擦（含访谈） |

**引用规则：** 「访谈」栏仅使用调研纪要与问卷中出现的评价；公开信息单独标注，避免与用户原话混写。

## 2. 竞品逐一对照

### 2.1 豆包（通用对话 AI）

| 维度 | 结论 |
|------|------|
| 定位（公开） | 通用消费级/办公向对话助手，覆盖写作、问答、草稿等广域场景。 |
| 核心能力 | 快速生成各类文本草稿；法律场景无强制溯源工作流。 |
| 价格/获取 | 个人可直接使用，门槛极低。 |
| 准确与幻觉（访谈） | 国内 AI 会「创制法条」；**豆包瞎编法条、硬说有匹配案例**；输出不简洁、AI 痕迹重；证明目的质量差（学姐级吐槽：「像一坨」）。 |
| 证明目的 | **不专项覆盖**；能生成但不可直接用，仍需大改。 |
| UI/账号摩擦 | 易用、几乎无专业库式账号摩擦；问题在可信与体例，不在登录。 |

**对证目启示：** 不能只拼「能生成」；必须拼可核验 + 法律文书短句体例 + 人审。

---

### 2.2 DeepSeek（通用大模型）

| 维度 | 结论 |
|------|------|
| 定位（公开） | 通用大模型/对话产品，偏推理与生成，非法律垂直工作流。 |
| 核心能力 | 合同等草稿场景与豆包常**互换使用**（访谈）；法律引用无专业库级强制核验。 |
| 价格/获取 | 个人易获取；成本感低于专业法律库。 |
| 准确与幻觉（访谈） | 与国内通用 AI 同类问题：幻觉、不可信引用、文书需人工大改；国外模型引国内法更差（法系差异洞察）。 |
| 证明目的 | **不专项覆盖**；可作为草稿源，不是交卷工具。 |
| UI/账号摩擦 | 低摩擦聊天体验；律师不敢直接用其引用。 |

**对证目启示：** 差异化不在「另一个更强聊天框」，而在证据目录段落的结构化产出与引用状态机（待核/已核）。

### 2.3 workbuddy（腾讯 WorkBuddy，通用/办公 AI）

| 维度 | 结论 |
|------|------|
| 定位（公开） | 腾讯全场景 AI 办公工作台：自然语言下任务，自主拆解执行，交付文档/表格/PPT 等可验收成果；含企业版治理能力。来源：腾讯云/WorkBuddy 产品页。 |
| 核心能力（公开） | 办公文件生成、本地/云端任务执行、多专家/Skill；非法律检索库。 |
| 价格/获取（公开） | 个人/企业订阅形态（以官网当期为准）；获取门槛低于机构法律库。 |
| 准确与幻觉（访谈） | 可用于**生成文书草稿**；合同场景明确规矩：**不让 AI 直接改合同，只出对照修改稿，律师自己改**。访谈总评仍归入「不好用；幻觉/太浅/缺国内（法律专业）数据」一类替代方案。 |
| 证明目的 | **无证据目录证明目的专项工作流**；可能被用来「顺便写一段」，质量与核验无产品级约束。 |
| UI/账号摩擦 | 办公向体验相对现代；摩擦主要在法律可信，而非 BBS 式检索 UI。 |

**对证目启示：** 「对照修订 + 人审终控」已被真实工作流验证——应产品化，而不是让 AI 直接改卷。

### 2.4 北大法宝（传统法律信息库）

| 维度 | 结论 |
|------|------|
| 定位（公开） | 国内长期法律法规/案例等信息库；律师、法务、高校机构订阅为主。 |
| 核心能力 | **法规/案例等专业检索与资料穷尽**是强项。 |
| 价格/获取 | 机构采购/按席订阅，**贵**（访谈）；公开价目通常询价制。 |
| 准确与幻觉（访谈） | 受访者将其归为律师圈**常用专业检索**之一，可信度预期高（非全市场量化排名）。 |
| 证明目的 | **不解决**「把证据组写成可交的证明目的短句」。 |
| UI/账号摩擦（访谈） | UI「像 20 年前 BBS」；专业但难用感强。 |

**说明：** 传统库与下方「法宝AI加」同属北大法宝生态；路演对比时以 **法宝AI加** 为 AI 层主对标，传统库保留为「能查」标杆。

### 2.5 北大法宝 · 法宝AI加（主对标 · AI 层）

> 产品入口公开页：`https://ai.pkulaw.com/` / `https://ai.pkulaw.com/home`。生态内常见子应用名：**法宝灵境**、**律爱多/律AI多**、**法宝来合同**、智能写作、MCP 法律检索服务等。公开材料常统称「法宝新AI / 法宝AI+」。

| 维度 | 结论 | 标注 |
|------|------|------|
| 定位 | 面向律师、企业法务、法律研究等的**法律智能应用平台**：检索、问答、知识管理、文书写作、合同处理等。 | `[公开]` 产品介绍页 |
| 核心能力 | **智能检索/问答**（自然语言找法条、案例、实务，答案可追溯出处）；**个人/团队知识库**；**智能写作**（文书草稿、可编辑、导出 Word/PDF）；**模拟法庭**；**法宝来合同**（清单/问答/法规关联审查）；另有 **MCP** 将法宝库能力接给外部 Agent（宣称降低幻觉）。 | `[公开]` ai.pkulaw.com、产品介绍摘要、律新社等公开演讲纪要 |
| 价格/获取 | 多应用独立开通；机构/律协统一采购常见（如公开律协开通「律AI多」通知）；智云商城可见部分标价参考（如法宝灵境公开页曾标「1500元/年起」量级，**以当期商城为准**）；个人完整价目多不透明。 | `[公开]` 律协通知、mall.pkulaw.com 等；具体成交价不臆测 |
| 准确与幻觉 | 公开强调答案出处、回原库核对、MCP「权威法条/案号查询」；官方亦声明生成内容不构成正式法律意见。访谈侧对「北大法宝」整体是专业检索标杆、贵、UI 老——**未单独点名「法宝AI加」好坏**。 | `[公开]` + `[访谈]` 仅整体法宝 |
| 证明目的 | 公开能力覆盖「法律文书生成/写作框架」等宽生成，**未见「证据目录·证明目的短句 + 待证事实对齐 + 对照终审」专项工作流**。 | `[推断]` 基于公开功能清单；非访谈原话 |
| UI/账号摩擦 | AI 应用层相对传统检索页更「产品化」；获取仍偏机构/律协通道。访谈「BBS 感」主要针对传统检索体验，是否完全转移到 AI 层**未在访谈核实**。 | `[公开]` + `[推断]` |

**对证目启示：** 法宝AI加已占「权威库 + 可溯源问答/写作」高地；证目**不拼全库与全文书**，只打穿举证交卷段落的可验收闭环，并把「出处」做成**待核/已核状态机 + 人审**，而非又一个智能写作入口。

### 2.7 法天使

| 维度 | 结论 |
|------|------|
| 定位（公开） | 聚焦合同起草/审查与中国合同库；近年法务 AI（Legal Al）等扩展合同智能体、知识库等；面向律师、法务、企业采购。来源：fatianshi.cn / mylegalai.cn。 |
| 核心能力（公开） | 合同模板库、审查点、Word/WPS 插件、合同相关 AI；非诉讼证据目录专项。 |
| 价格/获取（公开） | 个人/企业套餐与积分制等（企业版公开价目页有档位）；律所场景常见共享账号。 |
| 准确与幻觉（访谈） | **准确率相对更高**（相对通用 AI）。 |
| 证明目的 | **主战场在合同，不在证明目的证据目录工作流。** |
| UI/账号摩擦（访谈） | 律所常只买 **1 个账号**，扫码抢登、被踢下线，导致**少用**——账号摩擦是真实采用阻碍。 |

**对证目启示：** 垂直法律 AI「可以更准」已被用户认可；切入缝隙 = 诉讼举证段落 + 可核验 + **席位/协作体验不要重演抢登**。

## 4. 可借鉴 vs 可超越（重点：法宝AI加）

> 目标：告诉团队「学什么、不抄什么」。每条绑回证目三件套：**证明目的 · 可核验 · 人审对照**。

### 4.1 对法宝AI加 —— 可借鉴（Borrow）

| 可借鉴点 | 来源 | 落到证目怎么做 |
|----------|------|----------------|
| **答案带来源 / 可回原文** | `[公开]` 问答可追溯出处；MCP 法条/案号查询 | 每条引用必须有来源标识或核验路径；无出处 → **「待核」**，禁止伪装已确认 |
| **生成后仍可编辑再导出** | `[公开]` 智能写作可编辑、导出 Word/PDF | 证明目的短句行内编辑 → 终审后导出贴进所内模板（不做「一键交法院」） |
| **知识库/材料上传再问** | `[公开]` 个人/团队知识库 | MVP 用「证据组摘要导入」轻量落地；P1 脱敏后再分析（问卷） |
| **不宣称输出=正式法律意见** | `[公开]` 官方免责声明 | 文案对齐访谈：「AI 没有办法帮人担责」；默认人审终控 |
| **把检索能力产品化（非纯聊天）** | `[公开]` 应用分栏：检索/问答/写作/合同 | 证目主路径应是「导入→对齐→生成→核验→修订→确认」工作流，不是无约束对话框 |

### 4.2 对法宝AI加 —— 可超越 / 避免照抄（Surpass / Avoid）

| 超用或避开 | 为何 | 证目差异化 |
|------------|------|------------|
| **避开：宽文书「智能写作」当主卖点** | `[公开]` 可写意见书/起诉状等；访谈否定一键可上庭叙事 | **只做证据目录证明目的短句**；全文文书永不做主承诺 |
| **超越：证明目的专项体例** | `[推断]` 公开未见证据↔待证事实→短句列表闭环 | 事实绑定（日期/金额）、待证事实对齐、低 AI 痕迹——对症「像一坨」 |
| **超越：引用状态机（待核/已核）绑死定稿** | `[公开]` 有出处追溯，但是否阻断「未核就定稿」未知 | **存在待核或未终审 → 不可称定稿**（产品规则，不只展示链接） |
| **超越：对照修订（diff）而非直接覆盖** | 访谈合同习惯「只出对照稿」；法宝侧合同审查更偏清单/问答 | 客户 AI 稿/初稿 → **接受/改写/拒绝**；律师终审 |
| **避开：拼全量法库与数据壁垒叙事** | 访谈：「最难搞的其实是原始数据」 | 证目承认库壁垒；MVP 用可核验规则 + 必要时外链核验，不宣称自建法宝级库 |
| **超越：个人律师可达 + 少账号摩擦** | `[公开]` 机构/律协开通为主；访谈法宝「贵」 | 作业定位冲个人可用；多席位协作避开法天使式抢登 |
| **避开：模拟法庭/全案策略当 MVP 主打** | `[公开]` 有模拟法庭等宽能力 | 可记 P2 方向；今晚主打仍是证明目的交卷卡点 |

### 4.3 其他竞品（简表）

| 竞品 | 可借鉴 | 可超越 / 避开 |
|------|--------|----------------|
| 豆包 / DeepSeek | 低门槛入口、快速出草稿 | 幻觉与体例；证明目的质量；无待核机制 |
| workbuddy | **对照修改、不直接改原文**的真实习惯 | 法律浅、无证明目的工作流与引用状态 |
| 威科先行 | 输出回到依据、合规场景专业感 | 贵、不写证明目的；不做全库替代 |
| 法天使 | 垂直场景可以更准；Word 插件式贴合起草 | 合同战场非举证；**一账号抢登**必须避开 |

## 5. 访谈真实评价摘录（仅原文级已记录内容）

| 主题 | 评价（来源） |
|------|----------------|
| 证明目的质量 | AI 写证明目的「像一坨」（微信访谈） |
| 责任边界 | 「AI 没有办法帮人担责」（深度访谈金句） |
| 辅助定位 | 「有这个建议非常重要，因为律师他只要进行核验即可。」（深度访谈） |
| 数据壁垒 | 「最难搞的其实是原始数据。」（深度访谈） |
| 合同工作流 | 不让 AI 直接改合同，只出对照修改稿（微信访谈） |
| 通用 AI | 豆包瞎编法条、硬说有匹配案例；文书 AI 痕迹重、不简洁（微信访谈） |
| 专业库 | 法宝、威科贵；UI 像 20 年前 BBS（微信访谈） |
| 法天使 | 准确率相对更高；1 账号扫码抢登被踢，少用（微信访谈） |
| 材料整理方向 | 纯整理过浅，通用模型可做，可能加工作量（深度访谈决策） |
| 问卷 | 编制证据目录麻烦项含「撰写证明目的」「证据与待证事实对应」；隐去隐私才敢用 AI，且要能核对原文（律师问卷） |

> 以上未出现的主观评价（如对「法宝AI加」单独好坏的原话）**一律不写**。公开功能主张已在 §2.5 / §4 标注 `[公开]`。

## 7. 结论（给选题与路演）

1. **通用 AI 已占「能写」**：豆包/DeepSeek/workbuddy 解决草稿可达，不解决证明目的可交与引用可信。  
2. **法宝传统库 + 法宝AI加已占「能查 / 能溯源写」**：AI 加把出处、知识库、智能写作产品化——证目**借鉴溯源与可编辑导出**，**不拼全库、不拼起诉状写作**。  
3. **缝隙仍在：** 公开材料未见「证据目录证明目的短句 + 待证事实对齐 + 待核阻断定稿 + 对照终审」闭环；访谈痛点正好落在这里。  
4. **法天使**证明垂直可更准，但主战场合同 + 抢登摩擦；证目打诉讼举证段落并避账号坑。  
5. **竞争结论一句话：** 法宝AI加是「权威数据上的法律 AI 平台」；证目是「举证交卷段落的可核验工作流」——**学它的溯源，超它的证明目的专项与人审定稿规则。**
