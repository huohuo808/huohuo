# 演示案件简报 · 交通事故人伤

> 路演 / 作业演示专用 Mock 案。与 Expo App 内置样例一致。

## 基本信息

| 字段 | 内容 |
|------|------|
| 案由 | 机动车交通事故责任纠纷 |
| 案件名称 | 张某诉李某、某保险公司机动车交通事故责任纠纷 |
| 审理程序 | 一审 · 举证阶段（编制证据目录） |
| 演示角色 | 原告代理律师（主办） |

## 当事人

- **原告：** 张某（行人，受伤方）
- **被告一：** 李某（机动车驾驶人）
- **被告二：** 某财产保险股份有限公司（交强险 / 商业三者险承保方）

## 案情简介（口述可用）

2024年3月12日，被告李某驾驶小型轿车在本市某路口与行人张某发生碰撞。交警出具《交通事故认定书》，认定李某负全部责任。张某当日入住，诊断为右胫腓骨骨折等，住院至 3 月 28 日，医疗费合计 **48,632.50 元**。2024年6月8日司法鉴定：右下肢损伤构成 **十级伤残**。出院后仍有门诊复查与康复治疗。

原告拟起诉请求医疗费、伤残赔偿金等；当前任务是编制证据目录中的 **「证明目的」** 段落。

## 争议焦点（演示用）

1. 原告损伤及伤残等级是否成立、与本次事故是否有关  
2. 医疗费数额是否真实、合理、必要  
3. 后续门诊治疗与本次事故损伤的关联性  

## 待证事实（写入 App「待证事实」节点）

1. 原告因本次交通事故受伤并经法医鉴定构成伤残；  
2. 原告住院治疗产生的医疗费数额及必要性；  
3. 原告诊疗经过与后续治疗关联性。

## 演示话术提示

- 先点「生成」看短句是否绑定 **日期 / 金额**  
- 再进「核验」：前两条「已核验」，第三条因客户稿「第××条」标 **待核**  
- 「对照修订」对比空泛客户稿 vs 证目建议稿  
- 勾选律师终审后再导出——强调 **不做一键可上庭**
